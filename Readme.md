# 🧠 404BrainNotFound

*A chaotic parody IDE for when your brain crashes mid-code.*  
Part toy, part simulator, part existential debugging session.

This project is my playful take on what happens when your creative brain and your computer both go “404” at the same time.  
Built during the [Project CodeGen Hackathon](https://maximally.in), where weird, colorful, and joyful logic is celebrated.

---

## 🌈 Overview

*404BrainNotFound* is an interactive “fake coding IDE” that roasts you, throws emoji tantrums, and mocks your coding mistakes — all in the name of fun.  
You’re not building serious code here; you’re building chaos energy.  
Think of it as VS Code meets a clown at 3 AM.

---

## 🚀 How It Works

- Open the index.html file in your browser.  
- Type in the fake “editor.”  
- Watch chaos unfold — emojis, roasts, and random messages.  
- Laugh. Cry. Repeat.

No setup, no frameworks, no sanity required.

## 🎯 Hackathon Write-up

### 💡 What were you trying to build?
I wanted to build a parody IDE — something that feels like your brain glitched mid-debug and decided to start roasting you instead of helping.  
It’s a silly, self-aware environment where everything looks sort of functional… until it decides not to be.  
The goal was simple: *make people laugh at their own coding pain.*

---

### 🎨 Why is it playful?
Because it turns coding — usually stressful — into a toy.  
Instead of compiler errors, you get roast messages.  
Instead of stack traces, you get emoji storms.  
The app behaves like a mischievous sidekick rather than a serious tool.  
It’s chaotic, colorful, and full of unpredictable moments that remind you why building weird stuff is fun.

---

### 🧠 What’s surprisingly smart about it?
Underneath the absurd humor, the app actually has structure and logic:
- *Modular JavaScript design:* Separate files handle emoji rain, roast logic, and code-checking.  
- *Randomized responses:* Keeps every interaction unique.  
- *Humor-driven UX:* The interface feels alive — it reacts, jokes, and teases.  
- *Meta design:* It’s a parody that still works — the code itself becomes part of the joke.

It’s silly on the surface, but under the hood it’s built with deliberate organization — the kind of “crayon logic” the hackathon celebrates.
